# Overview

A Java-based Hotel Reservation System that allows users to view available rooms, book rooms, and cancel reservations through a console-based interface.

# Features

- View Available Rooms
- Book Rooms
- Cancel Reservations
- Manage Room Availability
- Simple Menu-Driven Interface

# Technologies Used

- Java
- OOP Concepts
- Arrays
- Scanner Class

# Project Structure

- Room Class
- HotelReservationSystem Class

# How to Run

1. Compile the program
2. Run the Java file
3. Select options from the menu
4. Book or cancel reservations

# Learning Outcomes

- Classes and Objects
- Constructors
- Arrays
- Loops and Conditions
- Menu-Driven Programming
